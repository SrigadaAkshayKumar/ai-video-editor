## Clean script (what the viewer will hear)

Most freshers spend months learning a big programming language before joining, and then, in the first month, the senior says one line, "Can you pull this data from the database?" Many freshers freeze, because nobody taught them the one skill that almost every project uses every single day. If you are a fresher waiting to join a tech company, stay with me. By the end, you will know the 5SQL, commands that cover most of your first year, a simple way to practice them in one hour, and the mistake that can delete real data on a real project. First, why this skill, and not another one. Almost every application stores its information in a database. Customer details, orders, bank transactions, test results to read that information, to check a bug, or to prepare a report, people write SQL. It is not a hard language, it reads almost like English. Here is the surprise. In many projects, a fresher is asked to check data long before they are asked to build a big feature. Testers use it to verify results. Support teams use it to find why something failed. Developers use it every day. So, if you learn only this one thing well, you will look useful in your first week. Now, the 5 commands. Command 1 is select, it means "show me this information". You write select, the column names, and from which table, for example, select name and marks from students. A database gives you a table with just those two columns. Command 2 is where it filters the rows. Select name and marks from students where marks is above 70. Now you see only the students who scored above 70. These two commands alone answer a surprising number of questions at work. Show me all failed payments from yesterday. Show me the users from Hyderabad, always start here. But here is the catch. Beginners write select * which means every column on a table with millions of rows. That can make this system slow for everyone. Ask only for the columns you need and add a limit so you get a small sample first. Command 3 is order by. It sorts the result. Order by marks descending puts the highest score first. Add a limit of 5 and you get the top 5 students. Command 4 is group by. And this is the one that makes interviewer smile. It groups rows and counts or adds them. Suppose you want to know how many students are in each department. You select department and count from students group by department. One short line and you get a small summary table. Think of it like sorting a pile of exam papers into one stack for each department and then counting each stack. Notice something important. Group by is how reports are made. When a manager asks how many orders came from each city this week, this is the command behind the answer. Command 5 is join. Real data is split across tables. One table has students, another has their marks. A join connects them using a common column like the student ID. Start by understanding it as a simple match. Rows with the same ID on both sides are put side by side. Once this clicks, 90% of the fear around SQL disappears. Now the trap, I promised you. Update and delete commands. If you write delete from a table and forget the where line, you delete every row. This is a very famous beginner mistake and on a real project, it can be a serious incident. So follow one rule. Before you run any update or delete, run the same condition as a select first and check the rows that come back. Never practice changes on real project data and in your first months, ask a senior to review any change before you run it. So here is your plan for this week. Install a free database tool on your laptop or use a free online SQL practice website. Create one small table of 10 students and write each of the 5 commands yourself. One hour is enough for a first round. Then repeat for 7 days, 10 minutes each day with new questions. Quick recap, select and where to read. Order by and group by to summarize. Join to connect tables and never delete without checking with a select first. Now tell me in the comments, have you ever written SQL or is this your first time?
