# Brand profiles (optional)

Only used when you say a video is for a particular channel/client ("this one is for my channel",
"edit for Acme"). Claude saves what you tell it here as `<slug>.json` so the next video for the same
brand reuses it: name, handle, channel id, audience, title formula + examples, accent colour, links,
intro/outro clips. Videos without a brand get none of this.
